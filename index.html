Crat Uploader

Crat Uploader adalah aplikasi otomasi pribadi untuk mengunggah video ke channel YouTube milik sendiri, Crat Create Fun.

Aplikasi ini menggunakan YouTube Data API untuk:

  • Mengunggah video Shorts terjadwal ke channel sendiri
  • Membaca statistik channel sendiri (views, likes, subscriber)
  • Membaca dan membalas komentar di channel sendiri

Aplikasi ini hanya digunakan oleh pemiliknya sendiri dan tidak dibagikan ke publik.
