Kebijakan Privasi — Crat Uploader

Terakhir diperbarui: Oktober 2026

Data yang diakses

Crat Uploader mengakses akun YouTube milik sendiri melalui YouTube Data API dengan izin (scope):

  • youtube.upload — mengunggah video
  • youtube.readonly — membaca statistik channel dan komentar
  • youtube.force-ssl — mengelola video dan komentar channel sendiri

Penggunaan data

Data hanya digunakan untuk mengelola channel YouTube milik sendiri (Crat Create Fun): upload video terjadwal, laporan statistik, dan moderasi komentar.

Penyimpanan dan pembagian data

  • Token akses OAuth disimpan di server pribadi pemilik dan tidak dibagikan ke pihak ketiga mana pun.
  • Tidak ada data yang dijual, disewakan, atau dibagikan untuk iklan.
  • Tidak ada pelacakan pengguna lain — aplikasi ini hanya dipakai oleh pemiliknya sendiri.

Penghapusan data

Untuk mencabut akses kapan saja: buka myaccount.google.com/permissions, pilih "Crat Uploader", lalu hapus akses. Token yang tersimpan di server akan dihapus atas permintaan melalui email di bawah.
